# Security reporting

This repository is an early research prototype. Security fixes target `main`;
there are no supported production releases yet.

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/PAG-droid/open-readiness-tower/security/advisories/new).
Include the affected revision, reproduction steps with synthetic data, and the
potential impact. Do not post credentials, confidential documents, or exploit
details in public issues.

If private reporting is unavailable, open an issue asking the maintainer for a
private reporting channel without including vulnerability details.
